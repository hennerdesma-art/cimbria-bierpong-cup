# Sicherheit – Cimbria Cup
- GitHub ist **öffentlich**. Keine Passwörter, Service-Role-Keys, SMTP-Credentials, GitHub-Tokens oder Supabase-Serversecrets veröffentlichen.
- Der Supabase Publishable Key in `js/cloud.js` ist bewusst öffentlich; RLS setzt Zugriffsrechte durch.
- Neun Tabellen verfügen über RLS; keine anonymen Schreibrechte auf Datenbanktabellen. Private Spielernamen können nur verifizierte Admins lesen.
- Die öffentliche Edge Function erlaubt atomare Gast-Anmeldungen mit Datenprüfung und Kapazitätslimit.
- Die Admin-Funktionen erfordern verifizierte Auth-Identität und Eintrag in der privaten E-Mail-Allowlist.
- Die Auth Redirect URLs müssen konfiguriert sein.
- Kein CAPTCHA/Rate-Limiting/Gast-Bearbeitungslink nach Entscheidung des Auftraggebers. Nicht ohne Aufsicht offen schalten.


## V5 Broadcast and team crest security
- `tv.html` has **no** admin token or authenticated API credentials. It reads only public tournament data.
- `tv_cues` has RLS: only administrator sessions may create cues; anonymous viewers can see cues for a published tournament only.
- Automatic cues are generated by private database triggers, based on verified Main Stage status transitions.
- `teams.icon_id` is validated against twelve built-in names in both the Edge Function and PostgreSQL CHECK constraint; no third-party URLs, user-uploaded files or arbitrary HTML are accepted.
- Registered player full names remain in the existing private `players` table and are not selected by the TV screen.
- The public repo never contains the administrator's password, private keys, SMTP credentials or a Supabase service-role token.


## Administrativer Komplett-Reset

- `public.cimbria_reset_tournament` ist eine geschützte, revisionskontrollierte RPC; nur `authenticated` kann sie ausführen. Sie delegiert an die private `SECURITY DEFINER`-Funktion, die serverseitig bestätigte aktive Hauptadmins gegen `auth.users`, `admin_users` und die E-Mail-Allowlist validiert.
- Rücksetzen ist nur mit der festgelegten phrase `CIMBRIA RESET` und identischem `p_expected_revision` möglich. Kein normaler Gast, kein anonymer Benutzer und kein Supervisor dürfen Daten löschen.
- Die private Archiv-Tabelle ist nicht über die öffentliche Supabase-API sichtbar; weder anonyme noch authentifizierte Benutzer haben `SELECT` darauf. Enthält personenbezogene Daten und muss entsprechend geschützt und nach dem gewünschten Aufbewahrungszeitraum verwaltet werden.
- Beim Reset werden Spielstände und alte TV-Cues transaktional gelöscht, während Auth-Identitäten und Konfigurationen erhalten bleiben. Nach dem Reset bleibt die öffentliche Teamanmeldung gesperrt, bis ein Admin sie aktiviert.


## Offizielle Regelszene (TV)

- Der neue `rules`-Cue kann über den bestehenden `cimbria_tv_control`-RPC nur von einem tatsächlich berechtigten Administrator ausgelöst werden. Anonyme Besucher haben nach wie vor keine INSERT- oder RPC-Schreibrechte.
- Die TV-Szene ist statischer Text und enthält weder private Spielernamen noch dynamisch generiertes HTML. Das erneute Anzeigen der Regeln ändert keine Ergebnisse oder Team- und Spielerlisten.
- Der TV-Sperrzustand bleibt bis `clear` oder einem späteren Cue bestehen. Diese Priorität kann die automatische Main-Stage-Animation unterbrechen, um aktuellere Ergebnisse anzuzeigen.
